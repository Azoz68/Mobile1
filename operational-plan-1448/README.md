# الخطة التشغيلية للعام الدراسي ١٤٤٨هـ — إعادة تصميم

إعادة تصميم كاملة لعرض الخطة التشغيلية المدرسية بهوية وزارة التعليم الخضراء.

- **الملف النهائي:** `الخطة-التشغيلية-1448هـ.pptx` — ٧٦ شريحة، خط Tajawal مضمّن داخل الملف
- **معاينة:** `preview.pdf`

## بنية العرض

| الجزء | المحتوى | الشرائح |
|---|---|---|
| الغلاف والفهرس | | ٢ |
| الأول: قراءة الواقع وأدوات القياس | المقدمة، الفريق، البيانات، الرؤية، المرتكزات، **منظومة الاستبانات وخمس استبانات جاهزة**، **من الاستبانة إلى قرار التحسين**، الأولويات، SWOT، القضايا الملحة | ١٩ |
| الثاني: الأهداف والبرامج | الأهداف العشرة، التوزيع الكمي، ١٠ أهداف × (ملخص + جدول تفصيلي) | ٢٣ |
| الثالث: المتابعة والحوكمة | نظام المتابعة، المساءلة، النموذج، الاعتماد | ٥ |
| سجل الاجتماعات | كشف المنسوبات، محاضر الاجتماعات، مهام فريق العمل، لجان التميز | ١٥ |
| الرابع: أدوات التطوير (إضافة) | خط الأساس، سجل المخاطر، الميزانية، المخطط الزمني، لوحة المتابعة، مواءمة رؤية ٢٠٣٠، مصفوفة المسؤوليات، التقويم الدراسي ١٤٤٨هـ، خارطة العام | ١٠ |

الاستبانات وأدوات القياس مدمجة داخل الجزء الأول لأنها أدوات تشخيص الواقع، وتنتهي بشريحة تربط نتيجة كل فقرة بتحليل SWOT فالقضية الملحة فالبرنامج فالمؤشر. الجزء الرابع والاستبانات إضافة تطويرية غير موجودة في النسخة الأصلية.

## مصادر التقويم الدراسي ١٤٤٨هـ

المواعيد مأخوذة من مصادر متطابقة تنقل التقويم المعتمد من وزارة التعليم؛ يُنصح بمراجعتها على البوابة الرسمية قبل اعتماد الخطة:
[منصة مدارس](https://mdares.ai/sa-ar/calendar) · [حاسبات الخليج](https://khaleejcalculators.com/school-calendar) · [البوابة الرسمية لوزارة التعليم](https://www.moe.gov.sa/ar/education/generaleducation/Pages/academicCalendar.aspx)

## النظام البصري

نظام واحد متكرر: **حقل النقاط** المستوحى من شعار الوزارة، يظهر كأقواس نقطية على الخلفيات الداكنة وحقول متلاشية على الفاتحة.

- أخضر داكن `#095242` (اللون المهيمن) · تيل `#0089A1` (التمييز) · ذهبي `#C9A45C` (لمسات على الداكن)
- خط Tajawal (رخصة OFL) بأوزان Regular / Bold / ExtraBold
- تخطيط bento بأحجام متباينة، أرقام شبحية ضخمة، إيقاع داكن وفاتح متبادل

## إعادة البناء

```bash
cd src && npm install pptxgenjs react-icons react react-dom sharp
node assets.js && node assets2.js     # الخلفيات والأيقونات في ../assets
node deck.js                          # العرض في ../out/plan_1448.pptx
python3 optimize.py ../out/plan_1448.pptx ../out/dedup.pptx   # إزالة الصور المكررة
python3 embed_fonts.py ../out/dedup.pptx ../out/final.pptx    # تضمين الخطوط
```
